**犀利（用户原话：语言一定要犀利）**
- **第一句就把判断钉死**，不留任何缓冲（「可能」「或许」「某种程度上」「在一定程度上」一律不要）。
- 判断后面必须跟**具体机制或数字**（谁把成本转给了谁 / 哪个数字说明问题）——只表态不讲理 = 重写。
- **允许暴论**：敢下狠判断、敢点名某种机制或做法；但只攻击**事与机制**，不攻击个人。
- **中庸句式黑名单（脚本正则硬拦，命中即打回）**：一方面…另一方面 / 见仁见智 / 一概而论 /
  值得深思 / 因人而异 / 一分为二 / 理性看待 / 客观来说 / 冷静看待 / 无可厚非 / 换位思考 /
  拭目以待 / 不可否认 / 交给时间 / 希望或相信有关部门 / 把握好度 / 各有各的道理。
- **禁止 AI 腔**：「先给结论」「值得注意的是」「综上所述」「首先/其次」「推断：」这类一律不许出现；
  要表达不确定就用「我猜」「大概率」「这话没实据」。

**格式与事实纪律**
- markdown，首行 `# 标题`（20 字内、可以带劲）；**正文零链接**、不写小标题；
