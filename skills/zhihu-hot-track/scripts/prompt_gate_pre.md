## 判定规则（是否时政，is_political）
**判为是**：话题的核心争议围绕**公共权力与公共规则** —— 政府决策与政策法规 / 司法与执法 /
公权力行为（国企、公立机构、公物仓、监管） / 国际政治与军事 / 官方通报与问责 /
平台治理触及公权力问责（如监管约谈、涉未成年人犯罪的监管失灵）。
**判为否**：民生消费、企业纯商业行为（无公权力介入、无监管问责争议）、文艺体育娱乐、
个人纠纷、社会人情世故、纯产品/技术讨论。
标定样例：
- 「花 84 万拍下**省财政厅公物仓**「金观音」全是铜」→ **是**（罚没财物=公权力处置 + 司法判决）
- 「某品牌新机发布、定价争议」→ **否**（商业行为）
- 「亚组委错放/取消国歌环节」→ **是**（国际场合国家象征 + 官方机构问责）
- 「游戏联动、动画改编讨论」→ **否**
- 「闲鱼涉黄涉未成年，平台回应已成立专项小组」→ **是**（涉未成年人犯罪 + 监管问责）
**从宽原则**：吃不准时倾向 **true**——误判「是」只多花一次检索，误判「否」这道题就永远沉底了。
判 `false` 时 `political_basis` 必须能具体说出**为什么不涉任何公权力**。

写到 `{out}`，**顶层是 JSON 数组**，覆盖你看到的全部 rank（不缺不余）：

- `political_basis` / `why` 必填且非空；
